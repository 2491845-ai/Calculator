# Калькулятор ППС

Страница: https://calculator-2491845.netlify.app/

Два поля: текущая сумма тарифа в админке до скидки и текущий уровень скидки ППС.

Уровни: 4%, 8%, 12%, 15%, 20%, 25%. Каждый месяц сумма в админке увеличивается на 5%, скидка переходит на следующий уровень. После достижения 25% дальнейшего роста нет.

Оплата клиента = сумма в админке × (1 − скидка). Прогноз показывает ближайшее продление и следующие 6 месяцев. Прирост считается от суммы в админке предыдущего месяца.

Файл index.html работает без сборки и зависимостей. Ввод сохраняется в браузере. Для публикации в Netlify используется каталог публикации ., заданный в netlify.toml.
