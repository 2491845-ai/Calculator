# Программа прогрессивной скидки

Страница: https://calculator-2491845.netlify.app/

## Расчёт по месяцам

Ввод: текущая оплата клиента после скидки и текущая скидка. Полная стоимость восстанавливается как оплата / (1 − скидка / 100); прирост считается от полной стоимости. Уровни: 0%, 4%, 8%, 10%, 12%, 15%, 20%, 25%.

Каждый месяц тариф до скидки увеличивается на 5% от предыдущего тарифа до скидки. Затем применяется скидка этого месяца. При старте с 0% первое продление остаётся без скидки; 4% применяются на втором. После достижения 25% тариф и оплата сохраняются. Прогноз показывает все шаги до 25%.

Пример: текущая оплата 100 000 ₽ при 4% → полная стоимость 104 166,67 ₽ → собрать 109 375 ₽ → оплата клиента 100 625 ₽ при 8%.

## Скачок скидки

Текущая скидка синхронизирована с основным калькулятором. Скачки доступны только на уровни до 15% включительно. Прирост для скачков с 0%: на 4% — +10%, на 8% — +16%, на 10% — +22%, на 12% — +28%, на 15% — +34%. С других скидок: 5% за каждый шаг между уровнями. База прироста — восстановленная стоимость до текущей скидки. Пример с 0%: 100 000 ₽ → 134 000 ₽ в админке → 113 900 ₽ клиенту при 15%. Резкие переходы на 20% и 25% недоступны.

## Публикация

Один файл index.html, без сборки и зависимостей. Ввод сохраняется в браузере. Каталог публикации . задан в netlify.toml. Расчёт идёт без промежуточного округления; интерфейс показывает суммы в целых рублях.
