# Калькулятор программы лояльности

Интерактивный калькулятор скидок с четырьмя сценариями, прогнозом на 6 месяцев и уровнями ППС РД.

Откройте `index.html` в браузере. Установка зависимостей и сборка не нужны.

## Публикация в Netlify

Импортируйте репозиторий в Netlify. Команду сборки оставьте пустой, каталог публикации — `.`. Настройка каталога уже указана в `netlify.toml`.

Ввод сохраняется локально в браузере пользователя.
